# QualityHub — distribuição

Canal público de instaladores aprovados e informações de versão do QualityHub para Windows.

O programa e o banco de dados funcionam localmente no computador de cada usuário. Este repositório não contém o código do produto, dados de projetos, credenciais ou chaves privadas.

Ainda não há versão aprovada para distribuição. Não existe `latest.json` até a publicação de uma versão estável homologada. Instaladores aprovados serão disponibilizados em Releases; atualizações exigirão confirmação do usuário e verificação criptográfica pelo aplicativo.

Autorizações por instalação são entregues separadamente pelo canal https://github.com/leokowales/quality-hub-access .
